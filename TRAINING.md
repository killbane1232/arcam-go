# Обучение модели для предсказания свечей

## Описание

Команда `train` предназначена для обучения модели в Ollama на исторических данных свечей. Модель обучается предсказывать 5 будущих свечей на основе входной последовательности свечей.

## Схема обучения

- **Вход**: N свечей (настраивается в конфигурации, по умолчанию 20)
- **Выход**: 5 новых свечей, которые должны соответствовать свечам в будущем
- **Формат данных**: OHLCV (Open, High, Low, Close, Volume), разделенные точкой с запятой

## Конфигурация

В файле `configs/config.yaml` добавлена секция `training`:

```yaml
training:
  enabled: false                    # Включить/выключить обучение
  model: "llama3.2:latest"         # Модель Ollama для обучения
  ollamaURL: "http://localhost:11434" # URL сервера Ollama
  inputCandles: 20                  # Количество входных свечей
  outputCandles: 5                  # Количество выходных свечей
  symbol: XBTUSD                    # Символ для обучения
  binSize: 1m                       # Таймфрейм свечей
  trainingDataPath: "training_data.csv" # Путь к файлу с данными
  epochs: 10                        # Количество эпох обучения
  learningRate: 0.001               # Скорость обучения
```

## Подготовка данных

1. Создайте CSV файл с историческими данными свечей в формате:
   ```csv
   timestamp,open,high,low,close,volume
   2024-01-01T00:00:00Z,50000.0,51000.0,49000.0,50500.0,1000.0
   2024-01-01T01:00:00Z,50500.0,51500.0,49500.0,51000.0,1200.0
   ...
   ```

2. Убедитесь, что файл содержит достаточно данных для создания последовательностей (минимум `inputCandles + outputCandles` свечей)

## Запуск обучения

1. Убедитесь, что Ollama запущен и доступен по указанному URL
2. Включите обучение в конфигурации: `training.enabled: true`
3. Запустите команду:
   ```bash
   go run main.go train
   ```

## Требования

- Go 1.25.1 или выше
- Ollama сервер (запущенный локально или удаленно)
- Файл с историческими данными свечей в CSV формате

## Формат данных для модели

Входные и выходные данные форматируются как строки:
- Каждая свеча: `open,high,low,close,volume`
- Свечи разделяются точкой с запятой: `;`
- Пример: `50000.0,51000.0,49000.0,50500.0,1000.0;50500.0,51500.0,49500.0,51000.0,1200.0`

## Обработка ошибок

Команда обрабатывает следующие ошибки:
- Недоступность Ollama сервера
- Отсутствие или некорректный формат файла с данными
- Недостаточное количество данных для обучения
- Ошибки API Ollama

## Логирование

Все этапы обучения логируются в консоль:
- Загрузка данных
- Подготовка последовательностей
- Процесс обучения
- Результаты обучения
