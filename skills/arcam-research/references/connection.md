# Подключение и диагностика

Предпочитай подключённые MCP-инструменты. HTTP endpoint по умолчанию — `http://127.0.0.1:8080/mcp`, **с `/mcp`**. Корень `http://127.0.0.1:8080` обслуживает веб-интерфейс. Адрес относится к машине, где работает клиент: для Hermes на другой машине localhost не указывает на Arcam пользователя.

## Codex

Добавь или исправь только соответствующую секцию конфигурации; сохрани остальные настройки:

```toml
[mcp_servers.arcam]
url = "http://127.0.0.1:8080/mcp"
enabled = true
# Только если сервер требует токен:
# bearer_token_env_var = "ARCAM_API_TOKEN"
```

Не записывай токен непосредственно в скилл. Переменная должна быть доступна процессу клиента. После изменения MCP-конфигурации переподключи сервер или перезапусти клиент; уже открытый чат может сохранить старый список инструментов.

## Hermes Agent

В активном профиле Hermes, по умолчанию `~/.hermes/config.yaml`, объедини с существующим `mcp_servers`:

```yaml
mcp_servers:
  arcam:
    url: "http://127.0.0.1:8080/mcp"
    # Только если сервер требует токен:
    # headers:
    #   Authorization: "Bearer ${ARCAM_API_TOKEN}"
```

Это Streamable HTTP; не указывай legacy `transport: sse`. После подключения обнаруживается `mcp_arcam_get_catalog` и другие инструменты с тем же префиксом. При поддержке установленной версией проверь `hermes mcp test arcam`; иначе проверь discovery и вызов каталога в новом чате.

Один и тот же каталог скилла совместим с обоими агентами: `SKILL.md` и references общие, `agents/openai.yaml` — метаданные Codex. В Hermes загрузи скилл через `skill_view(name="arcam-research")`, если этот инструмент доступен; для ссылок можно использовать `skill_view(name="arcam-research", path="references/contracts.md")` или прочитать файл относительно каталога скилла.

## Stdio

Если нужен отдельный локальный процесс, выполни бинарник Arcam с аргументами:

```text
/absolute/path/arcam/bin/arcam -mcp-stdio -data /absolute/path/arcam/mcp-data
```

Пути должны быть абсолютными. Каталог данных может принадлежать только одному процессу: HTTP и stdio нельзя одновременно запускать с одним `-data`. Для общей лаборатории обоих агентов используй один HTTP-сервер. Не удаляй блокировку и не завершай работающий сервер ради обхода ошибки. Stdout занят JSON-RPC, логи идут в stderr.

## Read-only smoke-test

При наличии Python 3.9+ запусти относительно установленного каталога скилла:

```sh
python3 scripts/mcp_smoke.py --url http://127.0.0.1:8080/mcp
```

Из другой рабочей директории укажи абсолютный путь к скрипту. Токен читается из окружения `ARCAM_API_TOKEN`; `--token-env SOME_VARIABLE` выбирает другое **имя** переменной. Скрипт не печатает токен, не создаёт версий/прогонов, не импортирует историю и не вызывает LLM. Он проверяет initialize → notifications/initialized → tools/list → get_catalog → validate_strategy и списки стратегий/данных/прогонов. Exit code 0 означает, что эти проверки прошли; запись и бэктест этим не проверяются. Скрипт рассчитан на stateless JSONResponse Arcam; полноценный универсальный SSE-клиент он не заменяет.

| Симптом | Действие |
|---|---|
| Connection refused / timeout | Проверь работающий процесс, адрес и сетевые ограничения среды. Не объявляй сервер сломанным только из-за запрета sandbox. |
| HTML, HTTP 404/405 | Проверь суффикс `/mcp`, метод POST и поддержку Streamable HTTP. |
| HTTP 401 | Проверь передачу токена клиентом; не выводи значение секрета. |
| HTTP 403 | Проверь Host/Origin и `ARCAM_ALLOWED_HOSTS`, reverse proxy и настройки авторизации. |
| Tools есть, результат с `isError` | Это ошибка вызова/данных, не доказательство поломки транспорта; прочитай сообщение и исправь аргументы. |
| History missing | Проверь точный источник, пару, интервал, `[from,to)` и прогрев. Не заменяй биржевые данные синтетикой. |
| `preparing` долго | Прочитай `progress` и `data_loads`: это дозагрузка истории. |
| Queue full | Дождись текущих заданий; не отменяй чужие эксперименты. |
| Каталог заблокирован | Подключись к уже работающему HTTP-серверу либо выбери отдельный каталог для теста. |

Первичные источники формата клиентов: [OpenAI — Build skills](https://learn.chatgpt.com/docs/build-skills), [Hermes — Creating Skills](https://hermes-agent.nousresearch.com/docs/developer-guide/creating-skills), [Hermes — MCP](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp). Контракт Arcam определён самим сервером и его `tools/list`.
