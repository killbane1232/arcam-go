Условия входа и выхода

Позиция: none / long / short. В выходах можно сослаться на сигнал входа: он проверяется как для пустой позиции. Сначала закрытие; новый вход возможен по следующему решению.

В ALL сначала проверяются индикаторы и позиция. LLM вызывается только при необходимости, затем правила проверяются повторно.

Позиция и риск

Используйте llm.enter_long, llm.exit_long, llm.enter_short, llm.exit_short в правилах. Значения 0–1; например ≥ 0.75. Подключение задаётся во вкладке «Настройки». Модель сохраняется в версии стратегии.

Задайте адрес сервера и модель. Проверка получает список моделей без генерации ответа. Сохранённые настройки применяются к новым прогонам и при возобновлении сессий.

LiquidAI/d1-2B · временный пресет

Выберите «EMA / LiquidAI d1-2B» в конструкторе. Для локального запуска нужен Ollama с поддержкой System One и установленная модель d1:2b.

ollama pull d1:2b

Модель возвращает четыре оценки входа/выхода; текстовое объяснение не генерирует. Адрес Ollama задаётся ниже.

Пустое поле ключа сохраняет текущий ключ. Ключи хранятся локально на сервере и не возвращаются в интерфейс. Модель по умолчанию можно подставить в конструкторе стратегии.

Непрерывное исполнение

Проверка рынка каждые 5 секунд

Сессия фиксирует версию стратегии. Для смены режима остановите сессию и создайте новую. Live использует реальные market-ордера Binance USDT perpetual, one-way mode. Stop loss / take profit контролирует этот процесс по текущей цене; при паузе или остановке сервиса они не работают.

AGENT RESEARCH INTERFACE

Лаборатория для вашей LLM

MCP позволяет модели создавать версии стратегий, загружать историю, запускать эксперименты и разбирать решения. Инструменты исследования не размещают реальные ордера.

Цикл проверки гипотезы
  1. get_catalog → list_datasets → list_strategies
  2. validate_strategy → save_strategy
  3. import_history — необязательно: run_backtest дозагружает пропуски
  4. run_backtest → get_backtest → get_decisions
  5. compare_backtests на одинаковых данных и отдельном проверочном периоде
Для stdio: arcam -mcp-stdio -data ./mcp-data. Один процесс владеет одним каталогом данных. Для доступа к истории веб-сервиса используйте HTTP /mcp.
