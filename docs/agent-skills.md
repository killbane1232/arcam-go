# Скилл Arcam для Codex и Hermes Agent

Один переносимый пакет: [skills/arcam-research](../skills/arcam-research/SKILL.md). Он содержит исследовательский процесс, контракт MCP/DSL, правила сравнения экспериментов, работу с LLM и read-only диагностику. Python нужен только для диагностического скрипта; основные операции выполняются через подключённый MCP.

## Codex

В этой локальной установке скиллы находятся в `~/.codex/skills`. Для установки из корня проекта без перезаписи существующего пакета:

```sh
mkdir -p "$HOME/.codex/skills"
test ! -e "$HOME/.codex/skills/arcam-research" && cp -R skills/arcam-research "$HOME/.codex/skills/arcam-research"
```

Современная документация также описывает общий пользовательский каталог `~/.agents/skills` и проектный `.agents/skills`; используй каталог, поддерживаемый установленным клиентом. Не ставь один пакет одновременно в несколько сканируемых каталогов.

В `~/.codex/config.toml` сервер должен указывать на `/mcp`:

```toml
[mcp_servers.arcam]
enabled = true
url = "http://127.0.0.1:8080/mcp"
```

Перезапусти/переподключи MCP после исправления URL. Пример запроса:

```text
Используй $arcam-research. Проверь подключение Arcam и объясни, какие данные доступны, ничего не запуская.
```

## Hermes Agent

Скопируй **весь каталог**, включая references и scripts, в skills активного профиля. Для профиля по умолчанию, из корня проекта:

```sh
mkdir -p "$HOME/.hermes/skills"
test ! -e "$HOME/.hermes/skills/arcam-research" && cp -R skills/arcam-research "$HOME/.hermes/skills/arcam-research"
```

В `~/.hermes/config.yaml` добавь сервер в уже существующий раздел `mcp_servers`, не заменяя остальные настройки:

```yaml
mcp_servers:
  arcam:
    url: "http://127.0.0.1:8080/mcp"
```

Адрес localhost работает, только если Hermes и HTTP-сервер Arcam находятся на одной машине/в одной сетевой среде. Для удалённого клиента нужен доступный ему адрес сервера.

В версиях Hermes с этой командой проверь `hermes mcp test arcam`. Пример запроса:

```text
/arcam-research Проверь EMA 12/26 на BTCUSDT, binance_futures, 1h, с 2025-01-01T00:00:00Z до 2025-02-01T00:00:00Z, капитал 1000, fee_bps=4, slippage_bps=2, без LLM. Покажи результат и причины первых сделок.
```

Авторизация, stdio и диагностика описаны в [connection.md](../skills/arcam-research/references/connection.md). Для совместной работы двух агентов используй один HTTP-сервер: два процесса Arcam не могут владеть одним каталогом данных.

## Быстрая проверка

```sh
python3 skills/arcam-research/scripts/mcp_smoke.py --url http://127.0.0.1:8080/mcp
```

Это read-only проверка handshake, всех 12 имён инструментов, каталога, валидации и списков. Успех не означает проверку биржевого импорта, LLM, ордеров или завершения бэктеста. Ошибка возвращает ненулевой exit code. `ARCAM_API_TOKEN`, если нужен, передавай через окружение.

Совместимость структуры сверена с [OpenAI Build skills](https://learn.chatgpt.com/docs/build-skills), [Hermes Creating Skills](https://hermes-agent.nousresearch.com/docs/developer-guide/creating-skills) и [Hermes MCP](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp). Hermes Agent на машине проверки не установлен; поведение внутри его полноценного чата здесь не проверялось.
